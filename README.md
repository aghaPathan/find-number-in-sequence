# Find Number in Sequence

A Python script that analyzes numeric sequences and counts occurrences of a target number.

## Overview

This interactive script takes user input for a numeric sequence, asks which number to find, and reports how many times it appears.

## Usage

```bash
python find_number.py
```

### Example

```
Enter sequence: 1 2 3 2 4 2 5
What number to find? 2
Result: 2 appeared 3 times
```

## Features

- Interactive user input
- Handles any numeric sequence
- Reports occurrence count

## Requirements

- Python 3.x
